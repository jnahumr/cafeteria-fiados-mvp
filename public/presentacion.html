El problema

Un cuaderno de papel que no cuadra

En muchos negocios pequeños de Honduras, el fiado —dejar que un cliente se lleve productos y pague después— se sigue anotando en una hoja de papel. El problema es que ese método falla todo el tiempo: cada cliente se anota a sí mismo lo que se lleva y muchas veces no lo hace, la hoja se moja, se rompe o se pierde, y la letra no siempre se entiende. Al cierre del mes las cuentas no cuadran, nadie sabe con certeza quién debe cuánto, y el negocio termina asumiendo pérdidas de dinero por descontrol. La persona a cargo pierde tiempo sumando a mano y, aun así, no puede confiar en el resultado. Es un problema real, cotidiano y que cuesta plata.

La solución

Control de Créditos

Control de Créditos es una aplicación web instalable (PWA) que reemplaza el cuaderno de fiados por un registro digital confiable. La persona a cargo registra cada fiado y cada abono, y el sistema lleva el saldo de cada cliente de forma automática y exacta. Ya no depende de que el cliente se anote ni de sumar a mano: en cualquier momento se sabe quién debe cuánto, con el detalle de qué se llevó y a qué precio. Está pensada para ser simple de usar en el celular, incluso con conexión inestable, porque funciona como una app instalada.

Funcionalidades

Qué hace la aplicación

  • Registro de fiados y abonos por cliente, con el detalle de productos, cantidad y precio.
  • Saldo automático: cada movimiento actualiza al instante lo que el cliente debe.
  • Precio congelado: cada fiado guarda el precio del momento de la venta, así el histórico no se altera si cambian los precios.
  • Catálogo de productos propio de cada negocio.
  • Búsqueda de clientes tolerante a mayúsculas y acentos, para no duplicarlos.
  • Cobro por WhatsApp: genera un recordatorio con el saldo y se envía con un toque.
  • Roles de dueña y empleado, con permisos distintos.
  • Multi-negocio: varias cafeterías usan la misma app, cada una aislada de las demás.
  • PWA instalable y con soporte offline del entorno de la aplicación.
Arquitectura

Cómo está construida

El producto sigue un patrón moderno de PWA sobre servicios gestionados. El frontend es una Single Page Application hecha con React y Vite, desplegada en Vercel (PaaS), que se encarga del build, el HTTPS, la CDN y los despliegues automáticos. El backend es Supabase (BaaS): una base de datos PostgreSQL gestionada, autenticación lista (email y Google) y seguridad a nivel de fila. El aislamiento entre negocios no se programa en el código de la app, sino que se declara en la base con Row Level Security y la función mi_negocio_id(), de modo que cada usuario solo puede ver y tocar los datos de su propio negocio.

Manual de uso

Cómo se usa, paso a paso

  1. Iniciá sesión con tu correo o con Google.
  2. Cargá tus productos en el catálogo (nombre y precio).
  3. Agregá o buscá al cliente al que le vas a fiar.
  4. Registrá el fiado: elegí los productos y la cantidad; el sistema calcula el monto.
  5. Registrá el abono cuando el cliente pague, total o parcial.
  6. Consultá el saldo: se actualiza solo y muestra quién debe cuánto.
  7. Cobrá por WhatsApp enviando el recordatorio con un toque.
Cliente

Un negocio real usándola hoy

El usuario real de Control de Créditos es la cafetería de la Asociación de Empleados Infra, en el Barrio Las Acacias, San Pedro Sula, que vende refrescos, snacks y pan dulce a los empleados. Llegué a ellos a través de una amiga que trabaja ahí y que me pidió una solución, porque llevaban los fiados en una hoja de papel donde cada cliente se anotaba solo —con el descontrol y las pérdidas que eso traía—. Hoy la app está en producción y en uso real con sus productos y sus clientes.
